# SEDINCO HR — Hệ thống Chấm công, Đơn từ & Tiền lương (Zalo Mini App)

Hệ thống quản trị nhân sự cốt lõi cho **CÔNG TY CỔ PHẦN VẬT LIỆU XÂY DỰNG SEDINCO** (4 phân hệ: Chấm công GPS/Wi-Fi, Đơn từ, Tính & Nhận lương 8h Sáng/Chiều chuẩn MISA, Quản lý nhân sự & tài khoản).

## Lệnh khởi chạy
- **Chạy Backend API (`sedinco_backend`)**:
  ```bash
  npm --prefix sedinco_backend run dev
  ```
- **Chạy & Build Frontend Zalo Mini App (`zalo-miniapp-frontend`)**:
  ```bash
  npm --prefix zalo-miniapp-frontend start
  npm --prefix zalo-miniapp-frontend run build
  ```
