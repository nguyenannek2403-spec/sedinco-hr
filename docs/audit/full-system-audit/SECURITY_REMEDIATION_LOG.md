## 2. Các điểm tồn đọng cấp thấp đã ghi nhận (Deferred / Operational Recommendations)

- **Chuẩn hóa Route Aliases Legacy:** Giữ nguyên các alias tương thích ngược (`/settings` vs `/permissions`, 3 mount `/departments`, các alias mobile/device) trong bản này để không gây đứt gãy client Mini App cũ đang phát hành; khuyến nghị lập lịch deprecate có phiên bản ở V53+.
- **Nền tảng Đa tiến trình (Multi-Instance Scaling):** Nếu mở rộng chạy nhiều instance Backend song song, cần chuyển `authController` `bankLookupRateWindow`, `clientErrorRateLimit`, và `permissionsCache` (10s) sang kho chia sẻ tập trung (hoặc giảm TTL cache phân quyền). Hiện tại trên single web service Render, `login_rate_limits`, `idempotency_keys`, và `media_upload_events` đã được lưu bền vững trên MySQL/TiDB.
